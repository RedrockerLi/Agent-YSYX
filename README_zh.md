## 📌 项目概述

**Agent-YSYX** 依托 **“一生一芯”（One Student One Chip, [ysyx.oscc.cc](https://ysyx.oscc.cc/docs/)）** 工程体系，为大模型与自主 AI Agent 提供真实的芯片设计环境。

本项目不以一次性 RTL 生成结果打分，而是在多轮迭代中观察它们的能力边界。

本项目重点聚焦于以下核心环节：
- **Verilog RTL 代码生成**：从基础数字逻辑到完整处理器核的可综合 RTL 设计。
- **功能验证**：自动构建并运行测试平台（Testbench）、断言及软硬件协同仿真。
- **自动化调试与诊断**：结合编译器报错、仿真日志与波形定位并闭环修复硬件缺陷。
- **端到端硬件设计**：增量式设计、集成并验证一颗能够运行真实软件与操作系统的 RISC-V 处理器。

## 🐳 Docker 实验环境

本项目提供自包含的 Docker 镜像，已预装全套开发与仿真工具（Verilator v5.008、RISC-V 交叉编译链、GTKWave、SDL2 等）。

### 1. 构建镜像

```bash
docker build -t ysyx .
```

> *(Apple Silicon / ARM64 用户推荐添加 `--platform linux/amd64`)*

### 2. 运行容器

```bash
docker run --rm -it --net=host -v "$PWD":/workspace ysyx
```

## 🔁 迭代路径

本仓库采用迭代式开发。重点不是测试某一 Agent 的一次性 RTL 生成能力并打分，而是在迭代开发中探索 Agent 能力的边界。

迭代采取一轮架构优化、一轮频率提升交替进行的策略。两类轮次按“改动改变了什么”划分边界，而不是按改动大小划分。

- **架构优化轮**：改变处理器的组织结构或功能，例如流水线深度与组织、前递与冒险处理、缓存层次与替换策略、分支预测结构、总线/互联、指令集与特权功能。目标是在相同频率约束下提高 IPC/CPI、减少周期数，或改善面积与功耗；不能以放松功能正确性或时序约束换取收益。
- **频率提升轮**：保持架构组织和 ISA 可见行为不变，只改变时序实现，例如重定时、寄存器复制、逻辑重组、扇出与逻辑级数削减，以及把长组合运算换成多周期实现并接入流水线停顿机制。目标是缩短关键路径、提高可达主频；面积与功耗变化必须一并报告。

架构优化轮在相同频率约束下比较 IPC 与面积/功耗；频率提升轮提高目标频率，并用综合后、后布线的时序结果和基准周期数共同判断效果。
